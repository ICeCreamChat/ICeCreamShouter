# ICeCream Shouter 腾讯云国内版完整操作流程

这份说明按第一次接触服务器的用户来写。正常情况下不需要输入 Linux 命令，也不需要自己配置 Nginx、Python、数据库或 HTTPS。

只操作下面这个项目：

```text
D:\ICeCoding\CloudRemoteShouter
```

不要操作另一个原始项目：

```text
D:\ICeCoding\OpenRemoteShouter
```

## 一、已经确认的资源

根据腾讯云控制台截图，现有资源可以直接使用：

- 腾讯云轻量应用服务器：4 核、4 GB 内存、40 GB 系统盘；
- 当前公网 IP：`175.27.212.68`；
- 域名：`icecreamchat.top`；
- 域名已经解析到这台服务器；
- 腾讯云账号中显示已有 1 条完成的 ICP 备案记录；
- 当前系统是 OpenCloudOS 9，并安装了宝塔面板。

这台服务器以后专门运行 ICeCream Shouter。我们会通过腾讯云“重装系统”清除原宝塔、旧网站、旧数据库和旧文件，并改用干净的 Ubuntu Server 24.04 LTS。

截图没有显示这条备案所对应的具体域名。重装前请打开“ICP备案 → 我的备案”，确认备案域名中确实包含 `icecreamchat.top`。如果备案的是其他域名，应先完成 `icecreamchat.top` 的备案再正式使用。

> 重装系统不可恢复。只有确定旧服务器内容全部不再需要时才执行。你已经确认这台服务器专门用于本系统，因此不迁移旧数据。

## 二、最终使用效果

部署完成后的正式地址：

<https://icecreamchat.top/>

日常使用不需要登录腾讯云，也不需要打开服务器：

- `ICe` 在网页中创建班级、教师账号和绑定码；
- 教师用手机或电脑浏览器登录网页喊话；
- 每间教室只需复制“教室端”文件夹，双击 EXE 并输入一次绑定码；

- 服务器重启或断网恢复后，服务和教室端都会自动重连。

## 三、重装腾讯云服务器

### 第 1 步：打开服务器详情

1. 登录腾讯云控制台；
2. 点击“轻量应用服务器”；
3. 打开实例 `ICeCream服务器`；
4. 在“镜像与应用”区域点击“重装系统”。

### 第 2 步：选择系统镜像

在重装窗口中：

1. 选择“系统镜像”，不要选择宝塔等应用镜像；
2. 选择 `Ubuntu Server 24.04 LTS`；
3. 登录方式选择“设置密码”；
4. 页面会显示登录用户名 `ubuntu`，保持不变；
5. 设置一个强服务器密码，并单独保管；
6. 阅读“系统盘数据会被清空”的提示；
7. 确认重装。

服务器密码不要发到微信群、教师群或公开聊天中。输入密码时看不到圆点或星号是正常现象。

### 第 3 步：等待重装完成

等待腾讯云实例状态重新变成“运行中”，通常需要几分钟。系统信息应显示 Ubuntu 24.04，而不是 OpenCloudOS 或宝塔。

## 四、检查腾讯云防火墙

进入该服务器的“防火墙”页面，确认存在下面三条入站规则：

| 用途 | 协议 | 端口 | 来源 |
|---|---|---:|---|
| 自动部署登录 | TCP | 22 | 全部 IPv4（首次部署用） |
| 申请证书和网页跳转 | TCP | 80 | 全部 IPv4 |
| 教师网页和教室长连接 | TCP | 443 | 全部 IPv4 |

如果规则已存在，不要重复创建。不要开放数据库端口，也不需要开放宝塔的 `8888` 端口。

## 五、检查域名解析

腾讯云“云解析 DNS”中，根域名应有一条 A 记录：

| 主机记录 | 记录类型 | 记录值 |
|---|---|---|
| `@` | A | `175.27.212.68` |

当前检测已经解析正确。服务器重装不会改变公网 IP 时，不需要修改这条记录。

如果以后腾讯云显示的公网 IP 发生变化，应把记录值改成新 IP，再运行部署脚本。

## 六、一键部署国内服务器

服务器重装完成并显示“运行中”后，在自己的 Windows 管理电脑上打开：

```text
D:\ICeCoding\CloudRemoteShouter
```

双击：

```text
deploy-tencent-server.bat
```

脚本会依次询问：

1. 正式域名：直接按回车，使用 `icecreamchat.top`；
2. 服务器公网 IP：直接按回车，使用 `175.27.212.68`；
3. 服务器登录用户名：直接按回车，使用 `ubuntu`；
4. `ICe` 管理员密码：输入两遍，至少 10 位，同时包含字母和数字；
5. 服务器 `ubuntu` 登录密码：上传和安装时按提示输入；如果安装程序再次询问 `sudo` 密码，仍输入同一个密码。

服务器登录密码输入时屏幕不会显示字符，输完直接按回车即可。

脚本会自动完成：

- 检查域名是否指向这台服务器；
- 上传国内版服务端；
- 安装 Python、Nginx、SQLite 和证书工具；
- 创建独立低权限运行账号；
- 创建数据库；
- 配置 WebSocket 反向代理；
- 申请并自动续期免费 HTTPS 证书；
- 配置开机自动运行和异常自动重启；
- 配置每日数据库备份，保留最近 14 天；
- 初始化最高管理员 `ICe`；
- 构建 Windows 单文件教室端 EXE；
- 生成教师端和教室端交付包；
- 自动打开正式网页和交付包文件夹。

安装完成后，黑色窗口会显示：

```text
全部完成。
正式网址：https://icecreamchat.top
管理员账号：ICe
```

## 七、第一次登录与创建班级

打开：

<https://icecreamchat.top/>

使用下面的信息登录：

- 用户名：`ICe`；
- 密码：运行一键部署脚本时设置的管理员密码。

进入“班级管理”，点击“**一键创建高中60班**”。系统会创建：

- 高一（1）班至高一（20）班；
- 高二（1）班至高二（20）班；
- 高三（1）班至高三（20）班。

已经存在的班级会自动跳过。只有最高管理员 `ICe` 可以创建、改名、启用或停用班级。

## 八、创建教师账号

1. 用 `ICe` 登录；
2. 打开“教师管理”；
3. 点击“创建教师”；
4. 填写登录用户名、教师姓名和初始密码；
5. 勾选该教师有权喊话的班级；
6. 点击“创建账号”。

教师账号数量没有程序内限制。教师只能查看和操作自己获授权的班级，也只能查看这些班级的历史记录。

教师第一次登录后应修改自己的密码。不要给所有教师共用 `ICe` 管理员账号。

## 九、给教师使用

一键部署完成后，交付包位于：

```text
D:\ICeCoding\CloudRemoteShouter\dist\delivery
```

教师可以使用任一种方式：

- 双击 `教师端.url`；
- 手机浏览器打开 `https://icecreamchat.top/`；
- 在手机浏览器中选择“添加到主屏幕”。

登录后选择班级，输入内容，选择通知类型后点击“发送喊话”。

也可以切换到“语音喊话”：按住录音按钮说话，松开后先试听；不满意可以重录，确认后再发送。教室端播放教师原声，不转文字，也不使用系统 TTS。语音最长 30 秒，播放完成后服务器会自动删除音频文件，历史记录只保留发送教师、班级、级别、时长和送达状态。

通知类型说明：

- **普通**：教室电脑右下角悬浮显示，默认 8 秒，完全静音；
- **重要**：教室电脑顶部横幅显示，默认 12 秒，并播放文字 TTS 或教师原声；
- **紧急**：教室电脑全屏显示，默认 20 秒，并播放文字 TTS 或教师原声。

语音喊话不能选择“普通”；切换到语音喊话时，网页会自动选择“重要”。三种通知到达时都会立即中断该教室正在显示或播放的上一条内容，也都可以在教室端手动关闭；语速和显示时长可以在网页的“更多设置”中调整。页面会显示教室离线、已发送、已收到、正在展示或处理失败。

重要和紧急的文字喊话使用教室电脑的 Windows 离线语音播报，重要和紧急的语音喊话播放教师原声。普通通知只显示，不发出任何声音。

### 设置全校公共禁言时间

只有最高管理员 `ICe` 可以修改时间表，所有教师都可以在网页“禁言时间”页面查看：

1. 用 `ICe` 登录，打开“禁言时间”；
2. 填写时段名称，例如“第一节课”，选择开始时间、结束时间和生效星期；
3. 一天有多个上课时段时，点击“添加时段”逐条添加；
4. 点击“保存时间表”。时间统一按服务器北京时间计算；
5. 进入表内时段后，教师点击发送会看到醒目提醒。点击“取消”，教室端什么都不会出现；点击“仍然发送”，消息按所选级别正常送达。

禁言时间不是强制封锁。系统负责提醒，不替班主任做决定。服务器在真正接收发送请求时还会再次校验时间，避免教师网页长时间打开后使用了过期状态。

## 十、绑定每间教室电脑

### 管理员操作

1. 用 `ICe` 登录网页；
2. 进入“班级管理”；
3. 找到目标班级；
4. 点击“生成绑定码”；
5. 在 15 分钟内把绑定码输入该班教室电脑。

绑定码只能使用一次。不要提前批量生成，因为过期后需要重新生成。

### 教室电脑操作

把下面整个文件夹复制到教室电脑的固定位置，例如 `D:\ICeCreamShouter`：

```text
D:\ICeCoding\CloudRemoteShouter\dist\delivery\教室端
```

然后：

1. 双击 `ICeCreamShouter.exe`；
2. 系统网址已经预置，不需要填写；
3. 输入管理员刚生成的绑定码；
4. 保持“随 Windows 开机自动启动”勾选；
5. 点击“绑定并开始接收”。

设置窗口中可以点击“普通”“重要”“紧急”三个本机预览按钮，分别检查右下角悬浮、顶部横幅和全屏样式；“测试本机声音”可以检查扬声器，不需要连接服务器。

绑定成功后，程序常驻系统托盘。以后不需要重复绑定。教室电脑不需要安装 Python、Node.js、.NET 或其他运行环境。

## 十一、正式验收

先只绑定一间测试教室，再完成以下检查：

1. 教室端托盘状态显示“已连接”；
2. 教师手机使用 4G/5G 能打开正式网址并登录；
3. 学校电脑使用校园网能打开正式网址；
4. 发送普通文字通知，确认右下角显示且没有声音；
5. 发送重要文字通知，确认顶部横幅显示并播放 Windows TTS；
6. 发送一条重要或紧急语音喊话，先试听再确认发送，教室播放教师原声；
7. 连续发送第二条，第二条应立即中断第一条；
8. 临时添加一个覆盖当前时间的禁言时段，确认发送前出现提醒，取消后教室端什么都不出现；
9. 再次发送并选择“仍然发送”，确认消息正常送达，历史记录显示“禁言时段确认发送”；
10. 网页历史记录显示语音类型和时长；
11. 语音播放完成后，服务器临时音频应自动清理；
12. 断开教室网络再恢复，教室端应自动重连；
13. 重启教室电脑，程序应自动在托盘运行。

测试全部通过后，再分发到其他教室。

## 十二、以后更新系统

以后你修改项目代码后，只需要在管理员电脑上再次双击：

```text
deploy-tencent-server.bat
```

脚本会自动完成以下事情：

1. 重新构建最新的 Windows 教室端单文件 EXE；
2. 计算更新文件的长度和 SHA-256，随服务器版本一起发布；
3. 更新国内服务器服务端和教师网页；
4. 保留服务器上的 ICe 账号、教师账号、班级、设备绑定和喊话历史；
5. 重新生成 `dist\delivery` 交付包。

教室端更新方式：

- 已经安装过支持自动更新版本的教室电脑，会在后台自动检查；
- 也可以右键系统托盘图标，点击“检查更新”；
- 或单击托盘雪花打开“教室电脑设置”，点击“检查并安装更新”；
- 下载完成后会自动重启，通常不需要重新输入绑定码；
- 本机 `config.json` 会保留，班级不会变。

如果某台教室电脑还运行早于 `1.1.0` 的旧 EXE，它没有自动更新能力，需要先退出旧程序，再把新的 `dist\delivery\教室端\ICeCreamShouter.exe` 放到原目录并运行一次；原来的 `config.json` 会继续保留，程序会自动迁移开机启动项。已经运行 `1.1.0` 及以上版本的电脑会自动更新到当前发布版本（本次为 `1.4.0`）。

数据库自动备份位置在服务器：

```text
/var/backups/cloud-remote-shouter
```

默认每天备份一次，保留 14 天。

## 十三、常见问题

### 网页打不开

检查：

- 腾讯云实例是否“运行中”；
- 防火墙是否允许 TCP 80 和 443；
- `icecreamchat.top` 是否仍解析到服务器公网 IP；
- 域名备案是否正常。

### 部署时提示连接失败

检查：

- 防火墙是否允许 TCP 22；
- 用户名是否为 `ubuntu`；
- 输入的是重装系统时设置的新 `ubuntu` 登录密码；
- 服务器是否已经完成重装。

### HTTPS 证书申请失败

通常是域名解析还没生效，或 80 端口没有开放。修正后重新运行一键部署脚本即可。

### 教室显示离线

确认教室电脑：

- 已运行 EXE；
- 托盘状态不是“连接中断”；
- 能在浏览器打开 `https://icecreamchat.top/`；
- 没有被管理员停用；
- 绑定的班级没有被停用。

### 安全注意事项

- 不要把腾讯云密码、短信验证码、SSH 密钥或 API 密钥发给任何人；
- 不要公开发送教室端生成的 `config.json`；
- `ICe` 管理员密码不要使用过短、重复使用或已经泄露的密码；
- 教师使用各自账号，不要共用最高管理员账号；
- 正式运行后不需要宝塔，也不要重新安装宝塔。
